# 🛡️ KidGuard - Parental Control Web Application

KidGuard is a comprehensive, full-stack parental control and child monitoring system built to help parents safeguard their children's online experiences in real-time. 

## 🚀 Live Repository
* **Project Source:** [https://github.com/SHREYASHREEN/kidguard](https://github.com/SHREYASHREEN/kidguard)

---

## 🛠️ Tech Stack & Architecture

* **Backend Framework:** Python (Flask)
* **Real-Time Communication:** Flask-SocketIO (WebSockets)
* **Database & ORM:** SQLite / SQLAlchemy
* **Authentication:** Flask-Login & Werkzeug (Password Cryptographic Hashing)
* **Frontend Interface:** HTML5, CSS3, JavaScript, Bootstrap

---

## ✨ Key Features

* **Dual-Module Dashboard:** Custom structural viewpoints and role-based access controls for Parent and Child user accounts.
* **Real-Time Emergency Alerts:** Immediate SOS warning system that triggers immediate alerts across dynamic components.
* **Web Activity Logs:** Automated collection and parsing of child browsing history and online timelines.
* **Content Filtering System:** Active client-side script integrations to capture and filter incoming string matches.
